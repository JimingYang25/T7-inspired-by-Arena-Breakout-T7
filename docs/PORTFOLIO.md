# 简历与项目展示

建议项目名：**T7 可穿戴近场深度感知与 Jetson 视觉部署**。

可以按实际负责范围使用：

- 将轻量 DualTac 深度模型接入摄像头推理链路，按 checkpoint 契约固定 RGB 归一化、320×240 输入、逆深度解码与近场概率输出。
- 实现 PyTorch FP32/FP16 与 ONNX Runtime 推理入口，增加固定形状 ONNX 导出、数值一致性检查、可视化、录像及逐帧性能报告。
- 完成板端测量后，再补充真实 Jetson Nano B01 的设备环境、延迟分位数、pipeline FPS 和内存指标。

参数量 937,227 来自加载后的模型统计。模型是已有 DualTacV2 资产，本仓库的新增贡献是部署适配、运行流程、导出与测量，不应重复包装为另一套新网络架构。

README 的桌面运行结果来自确定性合成输入，只证明运行链路。填写简历时，B01 的实测吞吐与近场实拍精度需要用对应设备和真实数据报告支持。
